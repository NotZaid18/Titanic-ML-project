# 🚢 Titanic Survival Predictor

A binary classification ML project that predicts whether a Titanic passenger survived.

## Tech Stack
- Python, Flask
- scikit-learn (Random Forest)
- Chart.js, HTML/CSS

## How to Run
pip install -r requirements.txt
python app.py
Open http://127.0.0.1:5000

## Features
- Live survival predictor with confidence %
- Confusion matrix
- EDA charts (survival by gender, class)
- Feature importance visualization
